# Mobile Application Subsystem

## Overview
This directory contains the mobile application developed for floor managers, line supervisors, and machine operators at Toyo Cushion Lanka.

## Responsibilities
- Instantaneous visibility into cut dimensions and volume metrics directly on mobile devices.
- Machine health and cut variance alerts / push notifications.
- Operator shift logging and quick batch status updates.
- Offline-first capabilities for factory floor environments with intermittent connectivity.

## Getting Started
Refer to the framework setup instructions (e.g. Flutter / React Native) when setting up development and target device emulators/hardware.
