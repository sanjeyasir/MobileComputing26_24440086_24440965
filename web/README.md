# Web Dashboard & Analytics Subsystem

## Overview
This directory contains the web management application for monitoring, tracking, and analyzing production and volume data from the Rubberised Coir Cutter Machine.

## Responsibilities
- Real-time monitoring of cutter machine operational state.
- Aggregated volume tracking across shifts, days, and batches.
- Historical data visualization, reporting, and export capabilities.
- Sensor calibration settings and administrative configurations.

## Getting Started
Refer to the framework-specific package setup once initialized (e.g., `npm install`, `npm run dev`).
